# LaDolorosa

Este proyecto ofrece un pequeño entorno para gestionar deudas y pagos en un grupo de personas o en un contexto financiero, minimizando el número de transacciones necesarias para cerras las cuentas.

## Formulation

There exists various ways of modelling the transaction minimization problem, some of which . In this case, we opted for a transport problem formulation, with a small tweek on its objective function.
